Interactive satellite map of City of Las Cruces public-facility HVAC units for a cleaning takeoff.

## What it does

- Esri World Imagery satellite basemap so you can inspect rooftops and HVAC units
- 35 building pins, selectable / deselectable from the sidebar
- Group filter chips and live totals (units, tons, CoolSaver reimbursement)
- Google Maps link on every pin and sidebar row (street address search)

Pins sit on Google Place / OSM building rooftops, not street-centerline guesses.
